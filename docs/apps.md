# 步驟二：各專案用途細節

在 Monorepo 架構下，不同目錄的應用程式有不同的部署與開發定位：

## 1. 核心功能指南

- **正式站部署價值**：
  - **全方位指南**：不只看 UI，連如何使用 Composables（如：如何接 API、如何處理資料狀態）與 Utils（如：時間格式化、字串處理）都有完整範例。
  - **規格準據**：當多位開發者同時進行不同專案時，此站台提供統一的開發規範與邏輯標準，避免重複造輪子。
  - **資產累積**：隨著核心包功能增加，此站台會成為松凌最重要的前端技術資產庫。

## 2. 開發練習區

- **本地整合價值**：
  - **風險控管**：在不發布 NPM、不影響 UI 參考站的情況下，模擬最複雜的整合情境。
  - **快速實驗**：適合用來嘗試新的技術方案或暫時性的邏輯測試。
