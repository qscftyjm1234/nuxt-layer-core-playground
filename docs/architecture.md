# 步驟一：核心架構定位指南

剛加入的夥伴，面對 nuxt-core 目錄，請依照您的「開發任務」來尋找檔案：

---

## 任務 A：我想新增或修改 UI 元件

- **路徑**：components/
- **說明**：
  - 如果是純按鈕、輸入框、清單等底層零件 ➡️ 請放 uiInterface/。
  - 如果是包含業務邏輯或特定排版的區塊 ➡️ 請放 uiBusiness/。
- **規則**：禁止直接寫 a-table 或 a-button，必須使用封裝後的組件。

## 任務 B：我想修改 API 請求或資料處理邏輯

- **路徑**：composables/
- **目標**：
  - API 請求定義 ➡️ useApi.ts。
  - 下拉選單資料 ➡️ useOptions.ts。

## 任務 C：我想調整全域設定 (語系、安全性、建置)

- **路徑**：core/config/
- **範例**：
  - 多語系檔 ➡️ i18n/。
  - 系統標頭與安全設定 ➡️ security.ts。

## 任務 D：我想新增單純的函式工具 (不含狀態)

- **路徑**：utils/
- **範例**：日期格式化、金額處理、字串裁切。

---

## 新人注意事項

1. **不要在 packages 直接執行開發伺服器**：請到 apps/playground-app 執行。
2. **遵守命名規範**：函式動詞必須符合規定 (詳細請見資源指南)。
