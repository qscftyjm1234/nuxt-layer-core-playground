# 步驟四：進階資源與支援

完成基本流程後，可以參考以下資源深入了解專案規範。

## 1. 查閱開發規範

請依照需求查閱以下內容：

- **[開發規範標準](../.agent/knowledge/development_standards.md)**：開發組件與邏輯必須遵守的標準。
- **[決策指南](addition_vs_extension_guide.md)**：協助判斷應該新增組件還是擴充現有組件。

## 2. 自助排錯與紀錄

如果遇到問題：

1. **[查看排錯紀錄](../.agent/knowledge/troubleshooting_log.md)**：確認是否有人遇過相同的問題。
2. **更新紀錄**：解決新問題後，請隨手將解法紀錄下來。
