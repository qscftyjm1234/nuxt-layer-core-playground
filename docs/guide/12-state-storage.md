# 狀態管理與儲存機制

為了維護應用的效能與安全性，所有開發者在處理狀態與本地儲存時，必須嚴格遵守以下準則。

## 1. 全域狀態管理

專案使用 Pinia 作為狀態管理工具，設定統一存放於 `stores/` 中。

- **使用時機**：只有資料必須「跨越多個無關聯情境共享」時（如：全域的用戶驗證層級、權限、系統語系配置等），才考慮使用 Store。
- **禁止濫用全域狀態**：如果是單一業務頁面內的範圍狀態（例如該頁面的分頁參數、開關、部分表格資料），一律應妥善宣告在對應的頁面或組件內，不可放置於 Store 中，以防止狀態管理無限膨脹與記憶體殘留。

## 2. 本地快取機制

當需要讀寫瀏覽器的本地快取（Storage）時，必須使用核心提供的安全封裝，例如 `useStorage` 工具。

- **禁止直接呼叫 API**：嚴禁於元件內自行調用 `window.localStorage` 或 `window.sessionStorage`。
- **安全保障**：使用核心層的封裝工具，框架得以確保對敏感快取內容實行加密保護、支援過期時間校驗，並防範潛在的首頁直出同步錯誤。

**操作要求：**
一律透過引進封裝的工具集提供讀取、寫入及清除的統一操作，杜絕型別與安全性漏洞。
