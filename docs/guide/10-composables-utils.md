# 實用開發工具函式 (Composables & Utils)

核心層提供了大量的工具函式，開發業務邏輯時，請盡優先查詢是否有現成的工具可以使用。

## 1. 常見 Composables 列表

以下列出 `composables/` 目錄中幾個高頻率使用的工具：

- **`useDateTime`**：處理日期的解析、計算、比較與格式化。
- **`useDebounce`**：提供防抖 功能，避免輸入或連擊造成多次請求。
- **`useFileUpload` / `useFileDownload`**：處理檔案上傳與流下載的標準流程。
- **`useModal`**：管理彈跳視窗的開關狀態與傳遞資料。
- **`useFormatter`**：處理數字千分位、特定格式的文字轉換。

## 2. Utils 工具函式

`utils/` 目錄下存放與被動視圖或生命週期無關的純函式工具。這些工具應滿足單元測試標準且無副作用。

## 3. 調用規範

- 確保透過核心模組統一的出口引入工具。
- 若發現欠缺某項通用工具，**請先評估是否適合加入 `nuxt-core` 中**。若評估具備跨專案共用價值，請將其補充於此處。
