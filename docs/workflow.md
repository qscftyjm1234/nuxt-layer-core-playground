# 步驟三：開發與 NPM 補版流程

請依照以下標準程序進行核心功能的開發與套件更新。

## 1. 開發環境初始化

1. 確認 Node.js 環境。
2. 執行安裝：`npm install`。

## 2. 本地實作與測試

1. 在 packages/nuxt-core 進行開發。
2. 使用 apps/playground-app 進行功能驗證：`npm run dev:playground`。
3. 確認修改內容符合松凌複用原則。

## 3. UI 參考站更新

1. 啟動 UI 參考站：`npm run dev:ui-docs`。
2. 確保新功能已同步至文件，供同仁參考。

## 4. 上傳新版本與版本管理

當功能開發完成且通過驗證後：

1. **檢查程式碼**：執行 `npm run typecheck` 確保沒寫錯。
2. **改版本號**：在 package.json 裡面增加版本數字。這不只是個數字，更是為了讓其他同仁在引用時，可以清楚分辨 v102 或 v103 版本的差異。
3. **上傳正式包**：依照指令傳到套件庫，讓其他專案可以選擇性地更新或保留在特定版本。
